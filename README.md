# ✍️ Handwritten Digit Recognition System

## 📌 About the Project

The Handwritten Digit Recognition System is a machine learning project that recognizes handwritten digits from 0 to 9.

It uses a Convolutional Neural Network (CNN) trained on the MNIST dataset to identify handwritten digits from input images.

The project is developed using Python and deep learning techniques.

## 🚀 Features

* Recognizes handwritten digits (0–9).
* Uses a CNN model for digit classification.
* Trains the model using the MNIST dataset.
* Predicts digits from uploaded images.
* Stores prediction history.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/karthik25-bojja/Handwritten-digit-recognition-system.git
```

### 2. Open the project folder

```bash
cd Handwritten-digit-recognition-system
```

### 3. Create a virtual environment

```bash

```

### 4. Activate the virtual environment



Install any additional libraries required by your application.
